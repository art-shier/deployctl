没有本地 Docker daemon，因此真实容器日志及轮转行为仍需在 Linux/Docker 集成环境验证。Manager 流程、标准输出/错误合并、有界子进程读取与超时分别由本地测试覆盖，不将它们声称为真实 Docker 验证。

多管理服务副本的随机负载均衡不在本次现有单中心架构中；内存查询需节点路由或共享临时机制后才能支持多副本。
