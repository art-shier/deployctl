# SSH 节点安装

管理端提供主机、SSH 端口、用户名和密码输入，探测并确认主机密钥后提交后台任务。密码仅驻留本次进程内存，不进入数据库、审计、命令行或回显。仅平台 owner 可以操作。任务记录保存目标、阶段和固定错误码，页面关闭后仍可查询；中心重启后不使用旧密码自动重试。

节点侧 Bash 安装器统一负责依赖检查和安装。要求 root（允许 SSH 用户 sudo）、systemd、Python >=3.10、Docker Engine >=20.10、Compose >=2.30。Ubuntu 22.04/24.04/26.04/26.10、Debian 12/13 缺少 Docker 时使用 Docker 官方签名 apt 仓库安装。已有可用 Docker 直接复用；版本过低、守护进程不可用、冲突软件包均报错，禁止隐式升级、卸载或重启已有 Docker。其他系统需手工准备依赖。

使用中心自带且校验的 CLI 安装 Agent 和 updater，注册后等待真实心跳，随后由 owner 按现有流程分配项目授权。现有节点身份不得被覆盖：首次版本遇到已安装 Agent 提示使用现有节点管理，避免误登记和打断工作。单台主机互斥、最多四个安装；SSH 全程校验已确认主机密钥，任务有期限。注册凭据一次性、过期后失效。原始远程输出不返回浏览器，只识别固定阶段，详细错误留在节点 root 私有日志。
